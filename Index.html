DecisionLab

Interactive decision-making under uncertainty

Prepared by Tomás Campillo Gómez · Grade 10E

Turn uncertainty into a structured decision.

Build a payoff matrix, compare four decision criteria, and test a sequence of decisions. All results update when the input data change.

01 · Decision setup

Enter alternatives, states of nature, payoff values, and probabilities. Use finite numerical values only.

INTERACTIVE MODEL
State probabilities
Enter percentages. The total must equal 100% to calculate EMV / Bayes.

02 · Decision criteria

Each criterion is calculated independently using all original alternatives.

LIVE RESULTS
How to read the criteriaMaximax = optimistic · Maximin = conservative · Minimax Regret = minimizes the maximum opportunity loss · EMV / Bayes = probability-weighted expected payoff.

03 · Model status

Input checks and calculation readiness.

04 · Staged filtering

Apply decision criteria in sequence. Each stage keeps the best-scoring alternatives among those that entered that stage. Ties are preserved.

ELIMINATION PROCESS
Default sequence: Maximax → Maximin → Minimax Regret → EMV / Bayes. You can customize the order.
