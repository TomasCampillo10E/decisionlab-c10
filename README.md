# DecisionLab – Interactive Decision Webpage

**Global Economics | Grade 10**

**Created by:** Tomás Campillo Gómez  
**Class:** 10E

## About the Project

DecisionLab is an interactive webpage designed to help users understand and analyze decision-making under uncertainty.

It allows users to create decision problems, compare alternatives, evaluate possible outcomes and apply different decision-making criteria.

## Main Features

### 1. Interactive Decision Model
- Add, edit and remove alternatives.
- Add, edit and remove states of nature.
- Enter and modify payoff values.
- Set probabilities for each state of nature.
- Select different currencies or payoff units.

### 2. Decision Criteria

The webpage calculates and compares four decision criteria:

- **Maximax:** Selects the alternative with the highest possible payoff.
- **Maximin:** Selects the alternative with the best worst-case payoff.
- **Minimax Regret:** Minimizes the maximum possible regret.
- **EMV / Bayes:** Calculates expected monetary values using state probabilities.

### 3. Staged Filtering

Users can apply decision criteria in stages, eliminating alternatives step by step until the final recommendation is reached.

### 4. Flow Diagram

An interactive flow diagram displays the filtering process, showing which alternatives survive each stage and which are eliminated.

### 5. Preloaded Examples

DecisionLab includes several sample decision problems that allow users to explore and test the different decision-making criteria.

### 6. Validation and Warnings

The webpage checks user inputs, identifies incomplete or invalid data and displays warnings when necessary.

The purpose of DecisionLab is to provide an accessible and interactive learning tool for understanding decision-making under uncertainty in Global Economics.
